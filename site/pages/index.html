Little orbs.
Big context.

An open-source, self-hosted home for AI companions. Plug in any model, connect any context and give every orb its own face.

Try the live demo Read the docs View on GitHub

What is an orb?

A model

Any provider you connect: a hosted API, a model on your own machine, or any OpenAI-compatible endpoint.

Its context

The notes and web pages it is allowed to read. An orb sees only what you switch on.

A face

Color, shape, eyes, mouth and an accessory, so you can tell your orbs apart at a glance.

Run it yourself

One container for the API and the web app. Your data stays on your server.

git clone {{repo}}.git
cd orbs
docker compose up -d

Open http://localhost:8080, then connect a model under Models. The quick start covers SQLite, API tokens and mobile builds.
