# Privacy

Orbs is a personal hobby project by Stijn ter Steege. This page explains what happens with your data when you use the Orbs software and this project's website. It's short, because almost nothing is collected.

## The short version

- The Orbs software you host sends nothing to me. There is no telemetry.
- The website uses no cookies, no analytics and no ads.
- I never sell or share personal data.

## The Orbs software

When you run Orbs, **you** decide what happens with the data in it, and it stays on your own server.

- **Your data stays with you.** Orbs, chats, context sources and API keys are stored in your own database. I have no access to them.
- **Model providers.** When an orb answers, Orbs sends your message and the context sources you linked to that orb to the model provider you chose, such as OpenAI, OpenRouter or a local model. That provider's own privacy policy applies to what it receives. A model running on your own machine sends nothing elsewhere.
- **Web page sources.** When you add a web page as context, your Orbs server downloads that page.
- **No telemetry.** Orbs doesn't report usage, errors or anything else to me or anyone else.

## This website

- **Hosting.** The website runs on GitHub Pages. GitHub may log technical data such as your IP address to keep the service secure; see the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- **No cookies, no analytics.** The website sets no cookies and doesn't track visits. Fonts are served from the website itself, not from a third party.
- **Light or dark mode.** If you use the switch, the website remembers your choice in your browser's local storage. It stays on your device, and the live demo uses the same setting.
- **Live demo.** The demo keeps its sample orbs and chats in your browser's local storage. That data never leaves your device, and "Reset demo" removes it. The demo doesn't call real model providers.

## GitHub and email

- The code, issues and discussions live on GitHub, where the GitHub Privacy Statement applies. Issues, comments and commits are public, so please don't post anything private there.
- If you email me, I only use your address and message to reply to you.
